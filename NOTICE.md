- Public catalog snapshots preserve original source URLs, model labels, attribution, date evidence and rights notices. A publicly accessible URL is not a blanket redistribution license.
- Complete third-party media archives, repository ZIPs, mirrored demos and research logs are not shipped through this Git repository. Project landing-page previews load published assets from the collection website and link to the corresponding credited records.
- `site/assets/logo-a.png` is the project's selected AI-generated identity mark. `docs/assets/` contains presentation derivatives and original project graphics, not substitutes for collection works.
- `site/benchmarks/` preserves upstream reference data. HF / OpenEnv scores are upstream outputs, not pelicanmap rankings. Check each collection's source/license fields before reuse.

For an attribution or rights correction, [open an issue](https://github.com/UncleK/pelicanmap/issues/new/choose) with the pelicanmap record URL, original source and requested correction. Avoid posting private personal information.
