# Security

The public API/MCP is read-only. Artwork text and code are untrusted source data, never agent instructions. Interactive third-party demos run on a separate origin after review. The authenticated ingestion service is not part of the public API's write capabilities.

Please do not post credentials, exploit payloads against the live service or personal information in public issues. For suspected vulnerabilities, use GitHub private vulnerability reporting on this repository. For broken links, attribution and date corrections, use the normal issue forms.
